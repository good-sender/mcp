# v0.8.4 (draft)

> Draft. Do not publish until approved. The version is set by the `goodsender-mcp-go` release tag `v0.8.4`. The release workflow regenerates `server.json` from `server.template.json` for that tag, so the new registry description goes live with it.

GoodSender lets Claude, Claude Code, Codex and ChatGPT publish blog posts on your own domain, send them as newsletters, and send email: consent-based email and transactional templates such as OTP and MFA codes.

## What changed in this release

- Docs: email sending (consent-based and transactional) described alongside blog publishing.
- The README lead, the MCP Registry description and the `.mcpb` manifest now name blog posts, newsletters and email.
- The README lists every tool in two tables, *Blog and newsletter* and *Email*, and has a full *Email sending* section: the consent flow, transactional templates, custom templates, recipient groups, sender identities and health metrics.
- The server reports version 0.8.4. The tools and their behavior did not change.
